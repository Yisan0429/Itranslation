# 开源译作

本分支用于存放社区贡献的翻译作品。使用 [Itranslation](https://github.com/Yisan0429/Itranslation) 翻译完成后，将译稿提交至对应分类目录即可。

## 目录结构

```
books/
├── literature/        # 文学
├── philosophy/        # 哲学
├── natural-science/   # 自然科学
├── social-science/    # 社会科学
└── technical/         # 技术文档
```

## 贡献方式

1. Fork 本项目
2. 使用 Itranslation 完成翻译
3. 将译稿放入对应分类目录
4. 向 `books` 分支提交 PR

## 命名规范

`[作者] 书名 [语言].格式`

例如：`books/natural-science/Charles Darwin On the Origin of Species [EN-CN].pdf`
